## alternative hypothesis: stationary
  • My data set is stationary do to the constant mean value over time and little variance increase in the data
  • We can also see that according to the Augmented Dickey-Fuller Test my data rejects the Null Hypothesis with a p-value of .01, therefore concluding my data is stationary

Because there is some trend and seasonality and because my data is stationary I decided to use the Holt-Winters Model

Forecasting Model Choice (Holt Winter Model)

  • I chose Exponential Smoothing because my data is stationary

  • Out of all three exponential smoothing models I chose the Holt Winter Model because there is both seasonality and slight trend

\[ \begin{align*} \hat{y}_{t+h|t} &= (\ell_{t} + hb_{t})s_{t+h-m(k+1)} \\ \ell_{t} &= .0849 \frac{y_{t}}{s_{t-m}} + (1 - .0849)(\ell_{t-1} + b_{t-1})\\ b_{t} &= .0001^*(\ell_{t}-\ell_{t-1}) + (1 - .0001^*)b_{t-1} \\ s_{t} &= .0001 \frac{y_{t}}{(\ell_{t-1} + b_{t-1})} + (1 - .0001)s_{t-m} \end{align*} \]
